# Water Relay · Campus to Cloud Round 1

## Idea brief

A ward volunteer often receives duplicate water-outage messages from the same street. Water Relay groups reports by ward and normalized location, puts essential sites first, and shows which signals contributed to the queue. It uses synthetic data and does not dispatch crews or contact residents.

## Build summary

Vanilla JavaScript and browser storage form the prototype. The hosting ZIP is prepared for AWS Amplify Hosting manual deployment. Once deployed, list Amplify Hosting as the service used. The data stays on the current browser. Shared multi-user data would require a separate backend and authentication.

## Demo script · 90 seconds

Open Water Relay, explain the intake form, then load sample reports. Show that two versions of Market Road are combined and that the clinic ranks first. Add another report to Market Road and point out the updated count and maximum outage duration. Reload to show persistence. Show the AWS-hosted URL only after deployment.
